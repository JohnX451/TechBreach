# Introduction 
Repository of TechBreach, a game by Cat Eye Games.
This is the re-uploaded version of the original Azure DevOps dev branch of the project. This branch represents the final state of our submission for the course MAI-BB-3-WS2024-MPRJ1.

# First time setup
Requires Unreal Engine 5.3.2 (not tested on older or newer versions). Clone repository, generate Visual Studio project files, run with Microsoft Visual Studio Community 2022 (or newer) or JetBrains Rider and build+run project.
